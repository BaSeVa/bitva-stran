# Битва стран

Браузерная игра-симуляция: карта мира из флагов, страны по очереди нападают на соседей, бросают по три кубика, и победитель забирает территорию проигравшего, пока не останется одна страна.

## Правила

- Атакующий выбирается случайно, защитник — случайный сосед (сухопутная граница или реальное морское соседство).
- Каждая сторона бросает 3 кубика. Кубики сортируются и сравниваются попарно, разница идёт в очки тому, у кого кубик больше.
- Очки умножаются на множитель от населения: ×1.1 от 10 млн, ×1.2 от 50 млн, ×1.3 от 100 млн, ×1.4 от 500 млн, ×1.5 от 1 млрд. При ничьей защитник устоял.
- Победитель получает всю землю и половину населения побеждённого.
- После хода с шансом 4% захваченная страна может восстать и вернуть свои земли.

## Возможности

- Игра за выбранную страну: каждый 3-й ход вы выбираете цель и сами бросаете кубики.
- Скорость 1×/2×/4× и турбо-режим до финала.
- Вертикальный режим 9:16 с записью видео (Chrome/Edge).
- Автосохранение эпизода, ссылка с «зерном» для повтора партии, статистика эпизодов.

## Используемые API

| Что | Источник |
| --- | --- |
| Контуры стран | [world-atlas](https://github.com/topojson/world-atlas) (Natural Earth, TopoJSON) |
| Население | [World Bank API](https://datahelpdesk.worldbank.org/knowledgebase/articles/889392) |
| Коды ISO 3166 | [i18n-iso-countries](https://github.com/michaelwittig/node-i18n-iso-countries) |
| Флаги | [flagcdn.com](https://flagcdn.com) |
| Кубики | [random.org](https://www.random.org), запасной — Web Crypto |
| Справка о стране | [Wikipedia REST API](https://ru.wikipedia.org/api/rest_v1/) |
| Русские названия | `Intl.DisplayNames` |
| Звук, голос, запись | Web Audio, Web Speech, Screen Capture + MediaRecorder |

## Запуск локально

```bash
node serve.mjs
```

Затем откройте http://localhost:5178. Сборка не нужна: всё в одном файле `index.html`.
